# 홈 화면 단순화 (2026-09-23)

## 변경 범위

`app/(tabs)/home/index.tsx`의 AS 홈 화면과 전용 스타일만 수정했다.

- 상단: 우리집 AS, 기존 알림 버튼/읽지 않은 알림 수.
- 본문: 집수리·AS 문의, 짧은 공사 종류 예시.
- 주 버튼: 수리·AS 문의하기. 밝은 모드/다크모드 모두 진한 녹색 배경과 흰 글씨.
- 보조 메뉴: 내 문의 내역, 근처 가게·장터.
- 중복 채팅 바로가기, 준비 중인 직접 해결 가이드, 긴 예시/안내 영역은 홈에서 제거.

기존 문의 폼, 장터/지도 탐색, 하단 채팅/내정보, 가게 관리, 알림 이동, DB는 변경하지 않았다. 장터 화면 함수와 장터 전용 스타일은 수정 전과 동일하다. 새 모듈 설치나 SQL 적용은 필요 없다.

## 확인 방법

현재 실행 중인 Expo 앱을 새로고침한다. 웹에서는 개발 서버의 `/home` 화면을 연다.

- `수리·AS 문의하기` -> 기존 문의 작성 화면
- `내 문의 내역` -> 본인 문의 목록
- `근처 가게·장터` -> 기존 장터/지도 탐색
- 알림과 하단 채팅/내정보는 기존 흐름 유지

## 되돌리기

프로젝트 루트에서 확인 후 적용한다. 패치는 이미 복구 방향으로 생성되어 있으므로 `-R`을 붙이지 않는다.

```sh
git apply --check docs/rollback-home-simplification.patch
git apply docs/rollback-home-simplification.patch
```

이 패치는 이번 단순화만 되돌린다. 기존 미커밋 변경과 다른 화면의 작업은 유지한다. 이후 홈 파일을 추가 수정해서 `--check`가 실패하면 강제 적용하거나 전체 파일을 덮어쓰지 말고 변경 부분을 비교한다.

수정 직전 홈 전체 사본은 `docs/backups/home-before-simplification-20260923.tsx.txt`에 있다. 당시 작업 파일 그대로 저장했으며 Git의 마지막 커밋 버전으로 되돌리는 방식이 아니다.

## 검증

- TypeScript 검사 통과.
- 홈 파일 ESLint 오류/경고 없음.
- 복구 패치 `git apply --check` 통과.
- 임시 사본에 복구 패치를 실제 적용해 수정 전 백업과 완전히 일치함을 확인.
- 기존 장터 화면 함수/스타일이 변경되지 않았음을 비교 확인.
- 실제 휴대폰 화면과 터치 동작은 별도 확인 필요.
