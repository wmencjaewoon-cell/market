# 첨부 HTML에 맞춘 AS 화면 (2026-09-28)

## 화면 구성

- 기존 `우리집 AS` 이름과 로고를 유지하며 AS 화면과 하단 메뉴를 시안의 파랑/주황 색상으로 변경.
- 고정 상단: 동네 선택, 실제 읽지 않은 알림 표시, 내정보 이동.
- 홈: 인사말, 파란 문의 영역과 주황 버튼, 3칸 바로가기, 누수/누전 문의 배너, 6개 수리 분야, 본인 문의 현황, 실제 가게 후기, 주변 가게 지도, 상담 안내.
- 하단: 홈 / AS문의 / 채팅 / 내정보. 지도는 별도 탭으로 다시 노출하지 않고 지도 보기 버튼으로 진입.
- 문의: 사진/영상 촬영 및 선택, 큰 첨부 미리보기와 첨부 전환/삭제, 선택형 증상, 직접 입력, 신청자 정보, 주소 변경, 희망일, 가게 선택, 상담 요청.
- AS 첨부는 사진/영상 합계 최대 5개. 기존 일반 견적 모드는 6개. 파일당 사진 10MB/영상 30MB 제한은 유지.
- AS 상세 설명은 시안에 맞춰 300자. 이름과 전화번호는 계속 필수.
- 탭 이동 시 작성 내용 유지. 완료한 문의는 초기화. 계정 변경 시 이전 계정의 초안 제거. 업로드 실패 시 기존 접수 건의 첨부 재시도 유지.
- 기존 `/estimate/create` 링크도 계속 동작하며 같은 헤더/하단 이동 제공.

## 실제 서비스에 맞춘 차이

- 시안의 파랑/주황을 사용하되 작은 화면에서 줄바꿈과 색상 대비를 보정. 파란 문의 영역과 안내 영역은 전체 너비로 표시.
- 준비되지 않은 AI 자동 진단, 음성 인식, 안심번호, 3분 견적/30분 출동/무상 보증 문구를 사실처럼 표시하지 않음.
- 음성 안내 위치에는 실제로 가능한 '영상에 목소리를 함께 담기' 제공. 음성 녹음/글 변환 기능은 추가하지 않음.
- 가상의 예약/기사 이동 중 상태 대신 본인의 실제 문의 제목과 접수일, 문의/채팅 이동 표시.
- 가짜 리뷰, 임의 별점, 영수증 인증, 가상 수리 가격 대신 기존 공개 인증 가게 후기만 표시. 없는 경우 빈 상태, 조회 오류는 재시도 표시.
- 가스/보일러 항목은 문의 분류이며 자가 수리 가이드는 제공하지 않음.
- 운영 DB의 스키마/권한/알림 수신자 정책과 기존 장터·가게 관리 기능은 변경하지 않음.
- SQL 실행, 패키지 설치, 네이티브 설정 변경은 필요하지 않음. 기기에 설치된 앱의 기존 사진/영상 모듈을 사용.

## 직전 녹색 화면으로 되돌리기

프로젝트 루트에서 다음 순서로 실행:

```sh
git apply --check docs/rollback-as-html-match.patch
git apply docs/rollback-as-html-match.patch
```

첫 명령이 실패하면 이 작업 이후의 추가 변경과 충돌한 것입니다. 강제로 적용하거나 `git reset --hard`를 실행하지 마세요.

이 패치는 이번에 수정한 5개 파일을 작업 직전 내용으로 복구하고 신규 소스/테스트 6개를 제거합니다. 이미 접수된 문의나 업로드 파일 등 운영 데이터는 삭제하지 않습니다. 문서와 백업은 남깁니다.

백업은 `docs/backups/*-before-html-match-20260928.txt`에 있습니다. 그 이전의 첫 화면 변경까지 되돌리려면 위 패치를 먼저 적용한 뒤 `docs/rollback-as-reference-redesign.patch`를 사용해야 합니다.
